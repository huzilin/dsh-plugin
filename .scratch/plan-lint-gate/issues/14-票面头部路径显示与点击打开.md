# 14: 票面头部显示文件路径并可点击打开（全渲染点）

**What to build:** 用户原话「所有的 ticket 都要支持在头部显示文件路径，并支持点击打开」。视图里每张票都来自一个真实文件，但页面此前只显示文件名——同一个 `01.md` 可能属于三张图，读的人无法判断手里这张是哪个文件。两项要求：①**头部显示文件路径**（同一性）；②**点击打开**（可达性）。

**Blocked by:** None — can start immediately.

**Source spec:** 用户本次会话口述；渲染点清单来自 `PlanView.tsx` 现况盘点。

## 拍板（2026-09-29，用户两项选择）

1. **覆盖范围 = 全部**：各列表卡片/行的头部 + 详情弹窗头部（用户选「全部：各列表卡片/行的头部 + 详情弹窗头部（推荐）」）——统一口径，凡显示 ticket 处头部都能看到路径并点击打开。
2. **打开目标 = DSH 右侧栏文件预览**（用户选「在 DSH 右侧栏打开文件预览（推荐）」）——走官方 `sidebarRight.openResource`，与聊天里点 `@文件`、文件树点开同一条通道，内容留在产品内、与会话并排。

## What to build

1. **`src/client/file-path.ts`**（新纯函数模块，无 React/DOM）：`fileAddress(sessionId, path)` 构造 `dsh-resource://file/session/<id>/<path>` 地址（镜像官方 `sessionFileAddress` 语法：段内百分号编码、`:` 保留字面量、**绝对路径带前导空段**）；`displayPath(path, cwd)` 相对化显示（仓外原样）。
2. **`PlanView.tsx`**：新增 `openFileInSidebar`（走 `ctx.get('sidebarRight').openResource`，服务缺失/宿主异常返回 false 不抛）与共用 `FilePath` 组件（等宽小字按钮、hover 高亮、`stopPropagation` 以免吞掉卡片的「打开详情」点击）。
3. **接线全部 ticket 渲染点**（14 处调用，覆盖 12 类视图）：详情弹窗头部（标题下一行独占）、Kanban 卡片、Table 行（新增 Path 列）、Relation 节点（主图 + ruled-out 侧栏，`NODE_H` 44→66）、Overview 行助手（标题+路径成列）、待拍板卡（文件名 chip 由路径行取代）、台账卡与组头（同上）、缺陷卡与组头（组头原写 `<effort>/<file>`，改 `ID + 标题` + 路径行）、推演票子页行、CasesView 卡头、串联图节点（`NODE_H` 56→68）。
4. **单测** `test/file-path.test.js`（`node --test`）：地址构造（绝对/相对/编码/分隔符归一）+ 相对化（含前缀误截与无 cwd 两处边界）。
5. **构建**：`npx tsdown --config tsdown.standalone.ts` 重建 `lib/client.js`。

## 落地注

- 2026-09-29 实施（本会话）。**地址语法一处坑**：首版 `fileAddress` 把绝对路径的前导 `/` 丢掉写成 `…/session/s1/a/b.md`，与官方 `sessionFileAddress` 的 `…/session/s1//a/b.md` 不符——`parseFileAddress` 靠那个空段把路径还原成绝对形式，丢了就还原不出。修正后单测钉死两形态（绝对带空段／相对不带）。
- **自包含取舍**：不 import `@deepseek-ai/dsh-util-workspace-path`（本插件零运行时依赖，与 `api.ts` 同款取舍），改为按官方语法复刻两个纯函数并加注释指路；宿主换地址语法时全站一起换，此处不是唯一耦合点。
- **测试环境坑（非本票缺陷，实证记录）**：隔离测试 profile 初建时 `dsh-better-sidebar` 解析到 **0.19.1**，点任意文件（含 better-sidebar **自己的**「文件」按钮）都抛 React #130（`TreePanel`/`EditorHost` 崩溃）；升到主 profile 同版 **0.22.1** 后正常。定性证据：①同实例换回**未改动的**旧 `lib/client.js` 仍崩；②崩溃由 better-sidebar 自带按钮独立触发——与本票改动无关。另：用户会话「DSH升级后侧边栏React报错」两小时前已记录同一错误，为既有问题。
- 隔离实例：`~/.dsh/profiles/planview-test/`（`link:` 挂本仓源码）+ `pnpm dsh --profile planview-test --port 3181`；主实例 :3080 全程未动。
