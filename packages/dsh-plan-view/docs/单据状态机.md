# 单据状态机（plan 视图五类单据）

> 更新：2026-09-24。词表正本 = plan-protocol 第三节；本文是插件视角的汇总镜像（解析口径 + 流转 + 计数口径）。状态词允许附注（如「已关闭（复测 PASS）」），插件取首词判色、附注独立展示。

## 1. 工单（ticket，frontmatter `status`）

```
open（开票）→ claimed（认领/派发，写 claimed_by + session）→ resolved（落码完成）
                └────────────────→ out_of_scope（不做/移出）
```

- 插件归一词表：`doing/in_progress/wip/in review` → claimed；`done/closed/complete/completed/shipped` → resolved；`abandoned/rejected/wontfix/cancelled/superseded` → out_of_scope；其余 → open。
- 未关单 = open + claimed（tab「🗺️ 地图 / 🎫 工单」计数口径）。
- QA 标记（2026-09-21 增）：frontmatter `qa_cases: true`（测例已构建）、`qa_tested: true`（测例已执行）、`qa_accepted: true`（验收通过）——卡片/详情以徽标展示；写入时机见 to-qa-testcases / run-qa-testcases。
- 图页签全绿（2026-09-22 增）：顶部 map 页签在图内工单（含根层松散票，与页签计数同口径）全部 `qa_accepted` 时显示绿色（边框/文字绿、hover 提示「全部工单已验收」）；`out_of_scope` 票不算未验收工作、不阻塞绿；空图/无工单不标绿。总览页与地图页共用同一选择器，绿色态一致。
- 执行登记（2026-09-21 增）：开工即 `status: claimed` + `claimed_by` + `session`（DSH `session-<uuid>` / zcode `sess_<id>`）；session 决定跳转（DSH）或恢复命令复制（zcode）。
- 票态两形态（2026-09-25 增，协议 §三 同步）：frontmatter 形态（to-tickets 系，`status` 写 frontmatter）；wayfinder 推导形态（`status` 不入 frontmatter，`## Answer` 带正文=resolved、`## Ruled out` 带正文=out_of_scope、`claimed_by`=claimed、其余=open，格式正本=wayfinder `TRACKER-MARKDOWN.md`）。两形态共享同一 type 词表。
- 票面终态词表（2026-09-24 协议 §三 补齐）：`task`/`impl` 终态 = `done`；`research`/`prototype`/`grilling` 终态 = `resolved`（允许附日期 `resolved <YYYY-MM-DD>`）；执行中 = `claimed`。归一不变：`done` 归入 resolved 显示类。

## 2. 待拍板文档（approval，frontmatter `status`，协议五态）

```
pending（待拍）→ closed（拍板结算）
              → superseded-by:<path>（被新文档取代）
              → abandoned（废弃不作）
```

- `active` 是活文档态（spec/map/台账等长期文件），不是拍板流转终点。总览/地图 tab 计数 = pending 数。

## 3. 挂账（ledger，正文 `- 状态:` 行）

```
阻塞中（有 - 阻塞: 字段且依赖票未全 done）
   ↘ 可启动（无阻塞字段，或依赖票全部 done）→ 已销（处理完 / 迁出留痕）
                                          → 已转票（恢复入原图立票）
```

- 一账一文件：全局 `.plan/ledger/挂账-NN-slug.md`、图内 `.plan/<effort>/ledger/`；台账 tab 计数 = 未销（可启动+阻塞中）；台账页默认筛「未销」。层级归属（2026-09-25 拍板）：全局台账只在第一层「📒 台账」tab；地图页台账子页只看图内台账（全部地图态 = 各图图内聚合），全局台账不进地图页。页面展示带号（2026-09-25 增）：台账卡片与串联节点均显示「挂账-NN」编号，编号取自文件名/正文 H1，与挂账带号纪律同源。
- 图内条目可写 `- 阻塞: <票NN,…>`（只允许引用本图票）；implement 落地后重算写回阶段；视图按依赖票实时计算（写回延迟不影响显示）。旧词「在挂」视为可启动。
- **引用带号纪律（2026-09-24 拍板）**：凡指称挂账一律写「挂账-NN」编号，禁止只用绰号；历史绰号引用括注编号（正本条款见 plan-protocol「挂账台账」条）。

## 4. 缺陷（qa-defect，正文 `- 状态:` 行，六词）

```
待修复 → 已确认 → 修复中 → 待复测 → 已关闭
                ↘ 挂起（不修，附注理由）
```

- 一缺陷一文件：`.plan/<effort>/qa/DEF-NN-slug.md`；缺陷 tab 计数 = 非「已关闭/关闭/挂起」的条数。旧单文件多小节形态只读兼容。层级归属（2026-09-25 拍板）：根层 `.plan/qa/DEF-*.md`（无图归属）只在第一层「🧪 测例&缺陷」tab；地图页缺陷子页只看图归属缺陷。

## 5. 图与 spec（map.md / spec.md，frontmatter `status`）

```
active（活图）⇄ closed（收口 = 该图全部票 done；挂账恢复可重开）
superseded-by:<path>（被新图取代）
```

## 横向纪律

- 「未关」态驱动 tab 计数（工单 open/claimed、拍板 pending、挂账 在挂、缺陷 待修复~待复测）；「关」态必须留痕不删文件。
- frontmatter `status` 管文档层，正文字段行管条目层，两层不混。
- `type` 值不在词表（task/approval/research/prototype/grilling/ledger/qa-defect）的文件按「说明 / 杂项」解析，不作单据校验对象（2026-09-24 协议 §三 补齐）。
- 无 `type` 但有 `status` 的旧格式/手写票按 `status` 归工单（兼容桥：wayfinder 现行票格式本就写 `type`，该形态只剩存量；完全无 `type` 无 `status` 的文件归「说明 / 杂项」，2026-09-25 协议 §三 口径修正）。
- 测试关联（2026-09-21 增）：`qa/cases.md` 一图一份不拆文件，由路径识别为 `cases` 类单列「🧪 测例」子页；测例与票的覆盖关系在串联画布按「票 NN」引用自动连线。
