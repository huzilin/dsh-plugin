## 二、《缺陷条目》`.plan/<effort>/qa/DEF-NN-<slug>.md`（一缺陷一文件）

> 落点：每条缺陷独立一个文件 `.plan/<effort>/qa/DEF-NN-<slug>.md`（原单文件 `defect.md` 多小节形态**只读兼容**——归档轮快照是旧形态，现行一律拆文件）。文件名 slug 取标题短语（去标点空格，≤14 字）。

### 文件状态头（必须是真 frontmatter）

首行 `---` 开、闭合 `---`。**不写 ```yaml 围栏、不写引用块**——围栏/引用块插件读不到（实测三种旧写法全不合规）：

```
---
type: qa-defect
date: <YYYY-MM-DD>
status: <五态之一>
origin: <readability-rescue / proactive / review / retrospective>
---
```

- `type` 固定 `qa-defect`（plan-protocol `type` 取值约定已登记）；
- `status` 用 plan-protocol 既有五态：`pending` / `closed` / `superseded-by:<path>` / `active` / `abandoned`——**不新造词表**。条目内缺陷全关闭写 `closed`，仍有未关闭写 `active`；
- `cases.md` 与 `test.md` **不加头**，不被 plan 视图识别（插件 qa 组按 `type: qa-defect` 白名单收文件）。

### 正文契约（插件解析依赖，字段行不得改形）

首行 `# DEF-NN 标题`，随后固定字段行：

```
- 严重度: <S1 严重 / S2 一般 / S3 轻微 / S4 建议；优先级 P0~P3 一并写>
- 类型: <rd / fe / arch / docs——既有 role_id，不用 backend/frontend>
- Assignee: <指派>
- 状态: <待修复 / 已确认 / 修复中 / 待复测 / 已关闭 / 挂起，六词照用、允许附注（如「已关闭（复测 PASS）」）——插件取首词匹配>
- 关联用例: <用例号，如 A-06 / B-08；多个逗号分隔>
- 发现源: <QA 轮 / 用户>
- 测试设计缺口: <用户渠道必填——缺哪个源/维度/通道；缺口当轮补进 cases.md 并追加 to-qa-testcases/references/case-library.md>
```

**关联线索**：详情文本写「票 NN」「挂账-NN」「tickets/NN-」即可被 plan 串联视图自动挂链，无人工映射表。

### A~E 五节（E 必填）

**A. 基本信息**：发现人 / 发现日期 / 所属版本 / 模块 / **环境信息**（库 + 服务 + commit）。
**B. 缺陷详情**：缺陷描述 / 复现步骤（编号）/ 预期结果 / **实际结果（原样报文或截图，非转述）** / 根因定位（如已知，代码级 file:line）/ 附注。
**C. 返工与复验记录**：状态（六词 + 允许附注）/ 原因分类（程序错误 / 需求变更 / 需求缺失 / 设计缺陷 / 环境 / 数据）/ 修复方案 / **复测口径（= E 节命令翻绿 + 回归基线数）** / 复测结果 / 关闭人-日期。
> 诊断方（diagnosing-bugs）修复后只回写本节。

**D. 归属判定**：**类型**（`rd` / `fe` / `arch` / `docs`，与字段行「类型」同值）+ 判定理由（证据：哪层的成因）。

**E. 最小复现入口（diagnosing-bugs Phase 1 交接，必填）**
| 字段 | 值 |
|---|---|
| cmd | [一条命令：驱动脚本 + 用例过滤，如 `python3 qa/qa_diag_min.py --case B-5g`；fe 缺陷如 `npx playwright test -g P-12`] |
| 环境变量 | [名称清单；值经 env_up 注入，不落地] |
| 前置 | [env_up 命令 / seed] |
| 末次运行输出 | [redacted 关键行，须为红] |
| 复现率 | [100% 确定性 / 竞速类：循环 N 次命中 M] |
| 预期绿信号 | [修复后该命令的通过判据] |

### 清单与统计的去处

- 原「清单总览」九列表**不再维护**——plan 视图缺陷页即清单（按图列出全部条目卡片）；`test.md` §1「遗留」行直接指向各 `DEF-NN-*.md` 文件。
- 「发现源统计」复盘表随 QA 轮写在 `test.md` 对应轮次节内，不单独成文件。
